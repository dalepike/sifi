QUICK ANSWERS (Without Reading Full Docs)
================================================================================

Q: How do I add a new notification type?
A: See PATTERNS-APPLIED-TO-USE-CASES.md section 1
   (3 steps: add to enum, create calculation function, add cron logic)

Q: How do I calculate a time window?
A: See QUICK-REFERENCE-PATTERNS.md "Time Window Calculations"
   (Pattern: new Date(now.getTime() + days * 24 * 60 * 60 * 1000))

Q: How do I prevent duplicate notifications?
A: See QUICK-REFERENCE-PATTERNS.md "Deduplication Pattern"
   (Use onConflictDoNothing with unique constraint)

Q: How should I scope queries to users?
A: See QUICK-REFERENCE-PATTERNS.md "CRUD with User Scoping"
   (Always add: eq(table.userId, userId) to where clause)

Q: What should I use for the cron job?
A: See QUICK-REFERENCE-PATTERNS.md "Cron Job Pattern"
   (Bearer token auth, batch processing with onConflictDoNothing)

Q: How do I handle user preferences with defaults?
A: See INSTITUTIONAL-LEARNINGS.md section 2
   (Auto-create on first access if missing, use DB defaults)

Q: What about recurring schedules?
A: See PATTERNS-APPLIED-TO-USE-CASES.md section 3
   (Extends maintenance interval pattern with recurrenceType field)

Q: How do I handle time zones?
A: See PATTERNS-APPLIED-TO-USE-CASES.md section 5
   (Store in UTC, format at boundaries, client interprets in local timezone)
